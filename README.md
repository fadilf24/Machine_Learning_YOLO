# Machine_Learning_Detect_Color_Bottle_caps
Project ini merupakan solusi lengkap untuk mendeteksi warna tutup botol (dark blue, light blue, other) menggunakan:
- YOLOv8 Object Detection
- Python CLI (bsort)
- ML Pipeline
- Docker Image
- CI/CD (GitHub Action: linting, testing, docker build)
- WandB Training Tracker
Features
- YOLOv8 model training
- Inference lewat CLI
- Config YAML
- Unit Test
- Code formatting: black,isort
- Code linting: pylint
- CI/CD full automation
- Dockerfile
- Jupyter Notebook
